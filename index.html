I'm Alejandro, a support engineer turning into a software engineer

Right now I'm a Technical Support Engineer at Microsoft, deep in Active Directory, Windows Server and the specific kind of chaos that happens when identity breaks across an enterprise. Before that I was at Cloudflare on application performance — DNS, TLS, WAF, Workers — until the layoffs in May. Before that, Cisco, on Meraki networking.

Four years of that leaves a mark. I've mostly been the person you call when production is already on fire, which means I learned systems from the failure side first: packet captures before assumptions, logs before docs. It's a weird way in, but it means I've seen what breaks at scale before I ever had to design something that wouldn't.

Now I'm walking to the other end of it — writing the software instead of triaging it. I'm finishing an IT degree at UNAM, teaching Linux and CTF methodology at PumaHat, and building agent tooling with Python and LangGraph. I write it all down in the blog, mostly so the next person can skip the parts I got wrong.
